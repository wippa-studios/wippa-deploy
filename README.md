# Wippa

**An open-source, AI-first Zapier alternative.** Build automations using no-code flows or TypeScript.

[Documentation](https://www.wippa.com/docs) | [Deploy](https://www.wippa.com/docs/install/overview) | [Integrations (200+)](https://www.wippa.com/pieces) | [Discord](https://discord.gg/2jUXBKDdP8)

---

### Key Features
- **Extensible:** Integrations ("pieces") are TypeScript npm packages with local hot-reloading.
- **MCP Native:** All 200+ integrations work out-of-the-box as MCP servers for LLMs (Claude Desktop, Cursor, Windsurf).
- **Builder Capabilities:** Loops, branches, auto-retries, custom NPM/Code steps, AI agents, and human-in-the-loop approvals.
- **Self-Hosted & Secure:** Full data control, network-gapped deployment, and enterprise-ready role management.

### Build Your Own Piece
Extend Wippa by authoring TypeScript integrations using our framework. Check out the [Contributor's Guide](https://www.wippa.com/docs/build-pieces/building-pieces/overview).
